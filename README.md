# paper-lens

arXiv から論文を自動取得し、日本語の解説記事を自動生成するシステム。

## 仕組み
収集・解析・執筆は Claude（エージェント）自身が実行主体となり、
処理コードや手法は .claude/skills/ 配下のスキルに内包される。
通常のアプリケーションコード（src/）は持たない。

## 使い方
ワークフロースキル `/write-article [検索条件]` を起点に起動する。
取得 → 選定 → 解析 → 執筆 → レビューループ → 出力 までを人間の承認なしで全自動実行する。
実行には `uv` が必要。スクリプトの依存（pypdf 等）は `uv run` が隔離環境で自動解決するため、
メイン環境を汚さず、手動の pip install は不要。

## 構成
- docs/      設計ドキュメント（地図）
- .claude/   エージェント・スキル定義
- work/      中間生成物
- output/    生成記事
