    削るな、迂回させろ：視覚トークンを「消さずに見送る」VLM 高速化手法 Reroute

    VLM（視覚言語モデル）を高速化する「視覚トークン削減」で、従来は低スコアのトークンを不可逆に削除していました。本研究は、視覚トークンの重要度が層の深さで変わることに着目し、削除する代わりに残差パスで「見送り」、後段で全トークン集合から再選択できるようにする学習不要の手法 Reroute を提案。計算量と KV キャッシュの予算を据え置いたまま、特に 88.9% 削減のような厳しい状況でグラウンディング精度を改善し、複数のバックボーンへ転移できることを示しました。
