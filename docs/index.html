    自分で作ったデータで自分を圧縮する：モデル圧縮の限界に挑む「requential coding」

    ニューラルネットワークをどこまで小さく表現できるかは、そのモデルがどれだけ「本質」を学んだかの指標になります。この論文は、生徒モデルが自分で生成したデータを使って学習し、教師モデルが「どのサンプルを使うか」を選んだ情報だけを記録する、requential coding（レクエンシャル符号化）という新しい圧縮手法を提案しました。既存の圧縮手法には 2 つの弱点がありました。量子化・枝刈り・訓練後量子化（PTQ）などパラメータを直接圧縮する手法は、符号長がモデルサイズに比例して増え、パラメータが実際にどれだけの情報を蓄えているかに鈍感です。もう一方の prequential coding は訓練の過程そのものを圧縮してパラメータ数への依存は避けますが、「厳密なデータ系列」を符号化するため、データが複雑（高エントロピー）だと符号長がデータセットサイズに比例して肥大化します。中核アイデアはたった一点、prequential coding を「生徒モデルを自己生成データで訓練し、教師の選択情報だけを符号化する」よう変更することです。各ステップで、生徒が既知シードの疑似乱数生成器（PRNG）で自分の分布から候補サンプルを複数生成し、教師が受理ルールで 1 つを選び、その「どれを選んだか」というインデックスを相対エントロピー符号化（REC）で符号化して、選ばれたサンプルで生徒を訓練します。教師モデル自体は送信不要で、生徒は記録された選択情報だけからすべてを復元できます。この工夫により、符号長は対数項・定数項を除けば実質的に「累積 teacher-student KL」に帰着し、データエントロピーの項が消えて、符号の長さがパラメータ数にもデータの複雑さにも依存しなくなります。教師の選び方には Teacher smoothing（EMA からの合成データ生成）と Iso-loss projection（同じ性能でより低い KL の教師を得る）という 2 つの改良を提案します。GPT-2 系 Transformer を OpenWebText・CIFAR-5M・FineWeb で実験したところ、requential coding は「損失 対 圧縮後モデルサイズ」のパレートフロンティアを支配し、1 トークンあたりのコストは prequential coding より 1〜2 桁小さくなりました。しかも直感に反して、大きいモデルほど圧縮しやすく、量子化の下限である「1 パラメータあたり 1 ビット」をも大きく下回りました。認証された圧縮サイズを PAC-Bayes 汎化限界に差し込むと、計算最適（Chinchilla）領域で従来最先端のロスレス 4 ビット PTQ を上回り、モデルを大きくするほど保証がタイトになります。1 点の工夫で、10 億パラメータ級の LLM にも最先端の汎化保証を与えられることを示した研究です。

    脳波の「かたち」で夢を見分ける ― トポロジーで夢検出に挑む PHINN-EEG（性能値はすべて未実証の「投影」）

    脳波（EEG）から「その人が夢を見ていたか否か」を検出する既存手法は、周波数帯ごとのパワー（スペクトル）に頼っていて、識別性能が AUC ≈ 0.70 で頭打ちになっています。この論文は、脳波を時系列の点群に変換し、その「かたち（トポロジー）」を持続的ホモロジー（persistent homology）という数学の道具で捉える初のフレームワーク PHINN-EEG を提案します。もっとも注意すべき点は、示されている性能値（AUC = 0.82〜0.90 など）が実験で測定した結果ではなく、既存研究に基づく事前の「投影（projection）＝目標値」であり、実データでの検証はこれからだと著者自身が繰り返し明記していることです。従来の夢検出は PSD（パワースペクトル密度）や catch22 で「脳活動がどれだけあるか（エネルギー）」を測り、REM で AUC ≈ 0.700、NREM で 0.586 が壁でした。著者らはこの壁の根本原因を、スペクトル手法が活動量は測れても「どんな幾何的なかたちをしているか」を測れない点にあると考え、測る対象を「エネルギー」から「かたち」へ切り替えます。中核は、目覚める直前の多チャンネル脳波を Takens 遅延埋め込み（埋め込み次元 d = 7 が代表値）で点群に変換し、Vietoris–Rips フィルトレーションで持続的ホモロジーを計算して、連結成分 β0・ループ β1・空洞 β2 を時間の関数として捉えた Dynamic Betti Curves を特徴にすることです。オイラー標数 χ(t) = β0 − β1 + β2 を用いた「夢状態は持続的ループを示す」という Geometric Dream Hypothesis を立てますが、これは前提ではなく検証すべき対象だと慎重に位置づけます。前処理→遅延埋め込み（5 秒窓・80% オーバーラップ）→Vietoris–Rips→特徴ベクトル化の流れで約 340 次元の特徴を作り、XGBoost で分類、rectified flow によるトポロジー条件づき脳波生成も用意します。投影値は REM で AUC 0.82〜0.90（弱い事前分布）／控えめには 0.58〜0.69、NREM で 0.72〜0.78、生成の被覆率 SCR は 60〜70%（Abstract では >30%）。評価は LODO と被験者単位分割でリークを防ぎ、DREAM データベースの公開サブセットの 1,462 覚醒エポックを使います。多チャンネル連結埋め込みの数学的保証のなさ、ボリューム伝導、リファレンスの異種性など 7 つの限界を著者自ら率直に開示しており、夢検出を「エネルギー」から「かたち」へ移すパラダイムシフトを構想として提示した、実証はこれからの論文です。

    アイデアには『血筋』がある ― AI が研究の系譜を追えるかを測る初のベンチマーク IdeaGene-Bench

    科学のアイデアは「白紙」から生まれるのではなく、生物のゲノムのように、先行研究の中核的な仕組みを受け継ぎ、欠点を修復し、組み換えながら進化していきます。この論文は、そうした「アイデアの血筋（系譜）」を AI が正しく追えるかを測る初のベンチマーク IdeaGene-Bench（IG-Bench）を提案しました。従来の AI 研究者の評価が検索の質・事実の正しさ・文章の流暢さ・新規性に偏っていたのに対し、この研究は「正しい仕組みを受け継ぎ、正しい欠点を直し、根拠とする系譜と食い違っていないか」という科学的系譜能力を問います。中心となるフレームワーク IdeaGene は 3 つの部品からなります。論文を niche・mechanism・observation・limitation・delta・claim の 6 役に分解し証拠ポインタを必ず添える最小単位「Idea Genome」、論文をこの表現へ変換する「Genome Extraction」、そして先行論文と後続論文の Idea Genome を役割ごとに突き合わせて継承・変異・消失・新規・外部輸入に分類する「GenomeDiff」です。ここで鍵になるのは、周辺の課題やデータセットを共有するだけの「共在（co-location）」ではなく、駆動する仕組みそのものを受け継ぐ「駆動継承」が系譜の決め手だという区別です。GenomeDiff のパターンは、mutation・adaptive radiation・hybridization・speciation（系譜あり）と niche competition・isolation（系譜なし）の 6 つの進化的ダイナミクスに整理されます。評価は 2 種類で、完全一致（exact match）で採点し T1〜T4 の 4 段階で理解を測る IG-Exam（42 タスク・1,029 問）と、Heredity・Variation・Selection の平均 PES で生成提案を採点する IG-Arena です。自然言語処理・CV・マルチモーダルに加え生物・化学・物理・材料・医学・数学の 10 領域にわたり、1,961 本の系譜トレース・1,085 個の Idea Genome・920 件の GenomeDiff で構成され、50 名の大学院生が品質を検証しました。結果、最も高いシステム（Claude Code + GPT-5.5 の足場）でも完全一致精度は 27.3% にとどまり、素の最強 LLM GPT-5.5 は 23.1% でした。難しさは T1 34.4%→T2 37.9%→T3 25.3%→T4 17.4% と生成に近い段階ほど増し、ツールの足場は検索（T2）は助けても一貫性（T4）は助けませんでした。系譜情報を増やすと PES は中央値で +4.4 向上し、その正体はほとんど「正しい親への接地（Heredity）」で、新規性ではありませんでした。今の AI は「それらしい文章」は書けても「筋の通った継承」はまだ苦手だという構造的な弱点を浮き彫りにし、今後の自動研究システムには検索力に加えて系譜の整合性を検証する構成的検証モジュールが求められると論じた研究です。

    動画を「生成しながら考える」AI ― 1万7千本の推論動画で鍛えた Wan-CoF

    動画生成モデルが「連続するフレームのつながり」を通じて推論する能力を、Chain-of-Frame（CoF）推論と呼びます。この論文は、その CoF 推論を鍛えるために 11 種類のタスク・17,312 本の推論動画からなるデータセット OpenCoF-17K を構築しました。従来の CoT（Chain-of-Thought）が静止画のような静的な視覚観測に頼るのに対し、CoF は初期条件の画像と指示から生成される連続フレームの発展そのものを推論とみなし、物が動く・変化するといった動的な遷移を扱えます。背景には、既存研究が外部ベンチマークへの汎化を検証していないこと、推論のための動画モデル内部のアーキテクチャがほとんど調べられていないこと、という 2 つの限界がありました。OpenCoF-17K は「初期条件の画像＋指示」を「目標の推論動画」とペアにしたデータで、480p・15fps・81 フレームに統一し、インスタンスベースレンダリング・専門家ガイドレンダリング・手続き的シーン合成・外部動画の再利用という 4 つの相補的なパイプラインで作られています。このデータで汎用の I2V モデル Wan2.2-I2V-A14B を LoRA（rank=32、DiT のデノイザーのみ）でファインチューニングしたのが Wan-CoF です。さらに、中間の推論状態を明示的に保持する 2 種類の学習可能な Reasoning Token も探索しました。視覚推論トークン vt は視覚潜在列に加わり自己注意で双方向にやり取りして空間に接地した低レベルの手がかりを、テキスト推論トークン tt はクロス注意の参照される側に加わりプロンプト非依存の高レベルな事前情報を担います。評価では、Wan-CoF が外部 4 ベンチマーク（MME-CoF 1.00→1.30、Gen-ViRe 0.304→0.391、VIPER 3.3→7.5、RULER-Bench 55.8→56.8）すべてでベースラインを一貫して上回り、伸びは時間的一貫性・物理・空間・論理といった推論寄りの下位項目に集中しました。カテゴリ別の伸びが教師データの種類とよく対応し、分布外への転移も確認されています。vt・tt の両変種はさらにヘッドライン指標を押し上げ、vt は持続的なグローバルな計画、tt はプロンプト非依存の事前情報という設計どおりの役割分担を見せました（トークン数は 16 をデフォルト）。より強い動画推論には「広範な時間的教師信号」と「中間推論状態を組織化する明示的な機構」の両方が必要だと示し、vt と tt の効果的な組み合わせを今後の課題として残した研究です。

    実世界で自分から動くAIエージェントを「5つの能力」で診断する ― ベンチマーク UniClawBench

    ブラウザやターミナルなど、身の回りのツールを自分で操作して仕事をこなす「能動的エージェント（proactive agents）」を評価するための新しいベンチマーク UniClawBench を提案した研究です。従来の評価が「オフィス」「リサーチ」といった応用シーン別だったのに対し、この研究は「どの能力が欠けると失敗するのか」を突き止める 5 つの能力軸（スキル使用・探索・長文脈推論・マルチモーダル理解・クロスプラットフォーム協調）でタスクを分類します。既存のエージェント評価には、自前コピーやキャッシュに頼る模擬環境と実環境のギャップ、1 ターンで終わる一発勝負、応用シーン単位の分類で失敗原因を切り分けられない、という 3 つの構造的な限界がありました。UniClawBench は、実ソフト・稼働中のブラウザ・ローカルファイルシステムを備えた Docker コンテナの中で、英語・中国語あわせて 400 タスク（5 能力 × 各言語 40）を実行します。あらかじめ記録した正解は価格変動などですぐ古くなるため廃止し、各タスクを細かく段階的な「完了チェックポイント」に分解して採点します。評価は、実行エージェント（評価対象）・隠れた監督エージェント（採点者）・ユーザーシミュレータの 3 役による閉ループで行い、監督からユーザー役へは「情報ファイアウォール」を通して粗い進捗シグナルだけを渡すことで、答えや採点基準の漏洩を防ぎつつ多ターンのやり取りを再現します。自動判定は人間の多数決と 92.0% 一致し、スコアも人間評価と強く相関（r=0.71、ρ=0.68）しました。結果として、最先端モデルでも成功率は 50% に届かず（最高でも Pass Rate 0.475）、中間スコアは高いのに最終的に合格に届かない「途中失敗」が全モデルに共通し、長文脈推論・マルチモーダル理解・クロスプラットフォーム協調が依然として困難であることが浮き彫りになりました。同じモデルでもフレームワーク設計で成績が変わり、監督サイクルを重ねるほど Pass Rate が向上（23.8%→29.5%→31.7%）することも示されています。エージェントの失敗の根本原因を能力軸で切り分けられる物差しを提供した研究です。

    タンパク質・分子・結晶の「構造そのもの」を推論の証拠として扱う科学基盤モデル SciReasoner

    この論文は、科学基盤モデル SciReasoner を提案しています。中心にあるのは、タンパク質・小分子・無機結晶という 3 種類の科学的な「構造」を、テキストの添え物ではなく参照できる証拠として扱うという発想です。具体的には、これらの構造を統一トークン語彙に変換し、1 つの自己回帰モデル（次の単語を順番に予測していくタイプのモデル）の中で構造と言葉を交互に織り交ぜて推論させます。既存の科学 AI は、構造を主に文字列として扱う LLM、基盤モデルの構造理解力に縛られるエージェント型システム、証拠を外に見せない予測器であるドメイン特化モデルのいずれも、「構造をそのまま表現すること」と「証拠にひもづいた推論」を切り離してしまう弱点を抱えていました。SciReasoner は、タンパク質を Foldseek（3Di トークン）、結晶を SLICES、3D 分子構造を ConfSeq という専用エンコーダで離散化し、自然言語とは別の埋め込みテーブルを持つ「分割されない」専用トークンとして、Qwen3-14B で初期化した自己回帰モデルへ渡します。学習は、構造トークンの意味を固定する継続事前学習と、強化学習で構造語彙を思考連鎖につなぐ self-bootstrapped な事後学習の 2 段階です。結果として 86 ベンチマーク中 67 タスクで最高性能（SOTA）を達成し、専門家モデルのある 26 ベンチマークでもそれらに一致または上回りました。低ホモロジーのタンパク質機能予測（Fmax 0.42→0.55）、逆合成（0.63→0.72、USPTO-50K の Exact Match 0.72）、RNA アイソフォーム（R2 0.59→0.86）、材料物性（生成エネルギー R2 0.895）などで強く、構造トークンを取り除くと性能が一貫して低下しました。答えを当てるだけでなく「なぜその答えなのか」を構造の証拠に照らして示せる説明可能性の両立を狙った研究です。

    言葉と形をちょうどよい細かさで結びつける ― 3Dの生成と理解を1つのモデルにまとめた ELSA3D
