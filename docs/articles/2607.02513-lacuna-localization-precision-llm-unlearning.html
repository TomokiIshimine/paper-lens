AIから知識を「消した」つもりが隠しただけ？ 消えた場所を検証できるテストベッド LACUNA

公開日：2026-07-02 arXiv：2607.02513 カテゴリ：cs.CL / cs.AI / cs.LG

この論文のひとことまとめ

大規模言語モデル（LLM）から特定の知識を後から取り除く「アンラーニング（unlearning）」が、本当にパラメータ（モデルの重み）から知識を消せているのかを検証する初のテストベッド LACUNA を提案した研究です。あらかじめ決めた場所に個人情報を埋め込んで「知識がどこに格納されているか」の正解を持たせることで、消去手法が正しい場所を狙えているかを初めて定量評価できるようにしました。その結果、既存の最先端手法は出力の上では知識を隠せていても、実際には知識を格納する重みを正確に狙えておらず、追加学習で知識が再び表に出てくる攻撃に弱いことが分かりました。

!

本論文の核心。「モデルがその情報を出力しなくなった」ことと「モデルの中から情報が本当に消えた」ことは別物かもしれない。LACUNA は知識の格納場所を先に固定して正解を用意し、消去手法が正しい重みを狙えたかを初めて定量評価する。既存の最先端手法は出力上は消せても実際の重みは狙えておらず、追加学習で知識が再浮上する攻撃に弱い。

なぜこの研究が重要か

LLM は学習データに含まれる個人情報（PII、personally identifiable information、個人識別情報）を記憶してしまうことがあり、プライバシー上のリスクになります。最も素直な対処は、学習データから個人情報を取り除いてモデルを再学習することですが、現在の LLM の学習コストを考えるとこれは現実的ではありません。

そこで代替として注目されているのがアンラーニングです。モデルを丸ごと作り直すのではなく、覚えてしまった特定の情報だけを後から取り除こうという考え方です。しかし、ここには落とし穴があります。「モデルがその情報を出力しなくなった」ことと「モデルの中から情報が本当に消えた」ことは、実は別物かもしれないのです。この研究は、その違いを見分けるための土台を作ります。

背景：何が問題だったのか

これまでのアンラーニング用のベンチマーク（評価用データセット）は、モデルが対象の知識を出力しなくなるかどうかという出力レベル（output level）でしか性能を測ってきませんでした。つまり、質問しても答えなくなればよし、という評価です。

ところがこの評価では、モデルのパラメータから知識が本当に消去（erasure）されたのか、それとも単に表に出ないよう隠蔽（obfuscate）されただけなのかを区別できません。実際、アンラーニング済みとされた知識が、巧妙に作った攻撃で再び表面化したり、少し追加学習するだけで復活したりする例が報告されており、「消えていなかった」ことがうかがえます。

これまでの評価出力レベルだけ

質問して答えなくなればよし、という評価。パラメータから消去されたのか、単に表に出ないよう隠蔽されただけなのかを区別できない。

必要なもの格納場所の正解

「ある知識がモデル内のどのパラメータに格納されているか」という正解情報（ground truth）。しかし現状、そうした正解は誰も持っていない。

既存の代替帰属手法は循環論法

在りかを推定する帰属（attribution）手法の結果を正解とみなす手もあるが、それでは「推定を正解として推定を評価する」循環論法になる。先行研究では、帰属手法が特定する重要ニューロンは入力間で大きく共有され、正解としては広がりすぎると指摘されている。

提案手法：何をしたのか

この研究の中核アイデアはシンプルです。知識をモデルに見せる前に、格納する場所（パラメータ）を先に固定してしまうというものです。後から在りかを推定するのではなく、最初から「ここに入れる」と決めて埋め込めば、正解は設計の時点で手元にあります。著者らはこれを「データを見せる前に格納場所を固定することで循環論法を回避する」と表現しています。

パイプラインは 3 つのフェーズからなります。

  1. フェーズ 1 ― 局在化した情報注入（Localized Information Injection）

    合成した架空の人物の個人情報を、あらかじめ決めたパラメータにだけ注入する。このために「マスク付き継続事前学習（masked continual pretraining）」という手法を使う。

  2. フェーズ 2 ― アンラーニング（Unlearning）

    評価対象のアンラーニング手法に、保持すべき知識（retain）を守りながら、記憶させた個人情報を消去させる。

  3. フェーズ 3 ― LACUNA による評価

    正解のマスクを使って、消去手法が正しい重みを狙えたかを示す局在化精度（localization precision）を測る。同時に、出力レベルの挙動と、モデルの一般的な有用性（utility）が保たれているかも評価する。

情報を特定の場所だけに閉じ込める仕組み

情報を特定の場所だけに閉じ込める仕組みが「マスク付き継続事前学習」です。個人情報のプロファイルをいくつかのグループに分け、各グループにモデル重みの一部を指し示す重複しないマスク（binary mask、対象の重みを 1、それ以外を 0 で表す印）を割り当てます。学習の逆伝播（backpropagation、誤差を使って重みを更新する計算）の際に、そのグループのマスク外にある重みの勾配（更新量）をゼロにすることで、指定した重みだけが更新されるようにします。マスクの対象は、モデルの各層の 5% にあたるパラメータで、フィードフォワード層と注意機構（attention）の重みに限定し、個々のパラメータ単位で細かくランダムに選びます。

各層の 5%

マスク対象のパラメータ割合（FF 層と注意機構の重み、パラメータ単位でランダム選択）

1,200

埋め込むプロファイル数（合成 PII コーパス PANORAMA の 9,674 から選抜）

4 フィールド

対象フィールド：email・出生都市・電話番号・運転免許証番号

1B / 7B

対象モデルのサイズ（10 億・70 億パラメータの 2 種）

埋め込む個人情報は、合成された個人情報コーパス PANORAMA（9,674 プロファイル）から 1,200 プロファイルを選んで使い、email アドレス、出生都市、電話番号、運転免許証番号の 4 種類のフィールドを対象にしました。予測しやすいものから、しにくいものまでを含めるよう選んでいます。対象モデルは 10 億パラメータ（1B）と 70 億パラメータ（7B）の 2 サイズです。

比較したアンラーニング手法

評価対象として、次のアンラーニング手法を比較しました。

勾配ベースSimNPO

勾配ベースの最先端手法。

局在化ベースAlphaEdit / MemFlex

知識の在りかを先に特定してから消す「局在化ベース」の手法。

上限の基準OracleGrad

著者らが基準として用意した「上限」の手法。正解の消去対象マスクをあらかじめ与えられ、その中でだけ編集する、いわば答えを知っている理想的な手法。

結果：何が分かったのか

まず、マスク付きの学習がモデルの一般的な能力をほとんど損なわないことが確認されています。マスク学習による重みの分布の変化を検出しようとした分類器の F1 スコアは 0.485 で、ランダムな推測（0.438）とほぼ変わらず、マスクの設計を単純に逆算する手立てはないことが示されました。一般能力のベンチマーク（ARC、HellaSwag、MMLU など）でも、学習前後で精度の差はわずかでした。

中心となる結果：局在化精度の低さ

中心となる結果は、局在化精度の低さです。email アドレス・1B モデルの場合、消去手法が正しい重みを狙えたかを表す ROC AUC という指標（1.0 なら完全に正しい重みを狙えており、0.5 なら無差別に重みをいじっており、0.5 未満なら主に狙うべきでない重みをいじっている、という読み方）で見ると、次の値になりました。

手法（email・1B） 局在化精度（ROC AUC） 読み方
AlphaEdit 0.500 無差別（狙えていない）
MemFlex 0.500 無差別（狙えていない）
SimNPO 0.515 ほぼ無差別
OracleGrad（正解を知る上限） 0.915 高精度で正しい重みを狙えている

読み方 正解を知っている OracleGrad だけが 0.915 と高精度で正しい重みを狙えており、既存手法はいずれもほぼ 0.5 前後にとどまりました。SimNPO がわずかに高いものの、依然として消すべき重みをほとんど狙えていません。

!

問題の核心。出力レベルの消去性能では SimNPO が最も強く、答えを知る OracleGrad にほぼ匹敵する（ただし有用性はやや大きく低下）。つまり SimNPO は出力の上ではうまく消せているのに、実際には正しい重みを狙えていない。出力を見ているだけでは、その事実に気づけない。

「隠しただけかどうか」を突く再浮上攻撃

この「隠しただけかどうか」を突くのが再浮上攻撃（resurfacing attack）です。アンラーニング済みのモデルを、学習に使っていない別の個人情報で少し追加学習し直し、消したはずの情報が再び出てくるかを調べます。email アドレスでの結果では、MemFlex と AlphaEdit は攻撃に非常に弱く、消したはずの情報の多くが復元されました。SimNPO はより頑健でしたが一部は復元されました。そして OracleGrad が最も漏洩が少なく、著しく頑健でした。

手法（email・1B） 追加学習で情報が復活した割合
MemFlex 約 87%
AlphaEdit 約 74%
SimNPO 約 13%
OracleGrad（正解を知る上限） 約 0%

注記 これらはグラフからの読み取り値のため、正確な数値は原論文の図を参照してください。局在化ベースの MemFlex・AlphaEdit が最も再浮上しやすく、正しい重みを狙えた OracleGrad が最も頑健、という対比が読み取れます。

なお、漏洩したプロファイルを手法間で比べると、SimNPO と OracleGrad が漏らすプロファイルは大きく重なっていました。これは、手法固有の失敗というより「そもそも消しにくいデータ点」が存在することを示唆します（ただし著者らは、これは小さな集合に基づく補助的・定性的な観察だと断っています）。数値フィールドでは SimNPO と OracleGrad が同程度に頑健になるといった例外も報告されています。

意義と限界

意義

この研究が示したのは、従来の指標で高性能でも（特に SimNPO）、実際には知識を格納する重みを狙えておらず、再浮上攻撃に弱いままになりうる、という点です。対照的に、正解の在りかを与えられた単純な手法 OracleGrad は、消去・保持・有用性の望ましい組み合わせを達成し、攻撃にも最も頑健でした。ここから、正確に狙うことが、より頑健なアンラーニングにつながるという示唆が得られます。

LACUNA の意義は、「知識がどこにあるか」の正解を提供する初のテストベッドとして、アンラーニング手法が正しいパラメータを狙えているかを初めて定量的に評価できるようにした点にあります。著者らは今後の方向として、出力レベルだけでなくパラメータを直接狙える手法の設計と、より正確な知識の局在化技術の必要性を挙げています。

限界

限界として、著者らは知識の局在化が常に現実的とは限らないと述べています。密なモデルでは、記憶が必ずしも一部の重みに強く集中して格納されるとは限らないためです。そこで、機微な実データを扱う学習では、あらかじめ記憶を特定のパラメータやモジュールに閉じ込めておく方が望ましいかもしれない、と示唆しています。また、本文の詳細な結果は主に 1B モデル・email アドレスについて報告されており、7B や他のフィールドの結果は付録に置かれています。

まとめ

LACUNA は、知識の格納場所を先に固定することで、アンラーニングが正しい重みを狙えているかを検証できるようにした初のテストベッドです。既存の最先端手法は出力上は知識を消せていても実際の重みは狙えておらず、追加学習で情報が再浮上しやすいことが明らかになりました。「出力から消えた」と「モデルから消えた」を混同しないことの重要性を、定量的に示した研究といえます。

用語集

アンラーニング（unlearning）
学習済みモデルから特定の情報を後から取り除くアルゴリズムの総称。
PII（personally identifiable information、個人識別情報）
個人を特定しうる情報。本研究では email アドレス・出生都市・電話番号・運転免許証番号を対象。
局在化精度（localization precision）
アンラーニングが、知識を格納している重みをどれだけ的確に狙えたかの度合い。本研究では ROC AUC で測定する。
マスク付き継続事前学習（masked continual pretraining）
マスクで逆伝播時の勾配をゼロにし、情報を特定のパラメータにだけ注入する学習法。
forget set / retain set
消去したい情報の集合 / 有用性を保つために残したい情報の集合。
再浮上攻撃（resurfacing attack）
アンラーニング済みモデルを別データで追加学習し直し、消したはずの情報が再び出るかを調べる頑健性テスト。真の消去と単なる隠蔽を区別する狙いがある。
ROC AUC（局在化の指標）
狙うべき重みが、狙うべきでない重みより高いスコアを得る確率に相当。1.0 で完全、0.5 で無差別、0.5 未満は主に狙うべきでない重みを改変。
OracleGrad
正解の消去対象マスクを与えられ、その中だけで編集する「上限」の基準手法。
PANORAMA
本研究で情報注入元に用いた合成の個人情報コーパス（9,674 プロファイル）。
