生成の途中で「キャンバス」を広げる — 出力サイズを自由度として扱う Expanding Flow Maps

公開日：2026-07-23 arXiv：2607.21585 カテゴリ：cs.LG

この論文のひとことまとめ

拡散モデルやフローマッチングといった近年の生成モデルは、最初に決めた「入れ物のサイズ」（画像なら解像度、文章ならトークン数）を最後まで変えられません。この論文は、生成の途中で次元やトークン数が増えていく道筋を定式化し、その上を流れる生成フロー Expanding Generative Flows（EFlow）を提案しました。さらに、それを少ないステップ数で走れるよう圧縮した（蒸留した）フローマップ Expanding Flow Maps（EFM）も併せて提案しています。中核は、状態をより高い次元へ持ち上げる「拡張作用素（expand operator）」と、持ち上がった状態をデータへ運ぶ「輸送写像（transport map）」の二部構成です。分子の 3 次元配座生成（連続空間）、分子グラフ生成と可変長テキスト生成（離散空間）の 3 タスクで検証され、既存の拡散手法より大幅に少ないステップ数で同等以上の結果を示しました。

!

中核のアイデアは「生成を、次元が増えていく空間の間の輸送として捉え直す」こと。部品は 2 つだけです。条件付きノイズで状態をより高次元の空間へ持ち上げる拡張作用素と、持ち上がった状態をターゲット分布へ押し進める輸送写像。この分解によって、出力のサイズそのものが学習と制御の対象になります。

なぜこの研究が重要か

画像生成にせよテキスト生成にせよ、いまの主流の生成モデルは「ノイズから始めてデータへ向かう連続的な変形」を学びます。拡散モデル（diffusion model）やフローマッチング（flow matching）と呼ばれる枠組みです。ここには暗黙の前提があります。ノイズの入れ物とデータの入れ物が同じ形をしていること、つまり最初に用意した固定サイズのキャンバスの上だけで話が完結することです。

しかし現実の生成対象は、サイズそのものが決まっていないものだらけです。解像度が違う画像や 3D 形状、長さの分からない音声や動画、何単語になるか事前に分からない文章。異なるモダリティが混ざったデータでは、そもそも内在する次元が対象ごとに違います。固定キャンバスの前提は、こうした対象と正面から衝突します。

もう一つの流れが「少ステップ生成」です。拡散モデルは高品質な代わりに、生成に数百から千回のネットワーク評価を要します。これを 1〜2 回程度に圧縮する枠組みとして登場したのがフローマップ（flow map）です。この論文が掲げる問いは、その二つを同時に満たせるかというものでした。原文の言葉では「推論時に次元を適応的に変えながら、連続データと離散データの両方の少ステップ生成をどう可能にするか」です。

背景：何が問題だったのか

まず用語を整理します。

確率的補間路（stochastic interpolant） とは、ノイズの分布 p_0 とデータの分布 p_1 の間を連続時間でつなぐ経路のことです。もっとも素直な線形補間は、ノイズ x_0 とデータ x_1 を時刻 t で混ぜた I_t(x_0, x_1) = (1−t) x_0 + t x_1 という形をとります。この経路に沿ってどちらへ動けばよいかを表すのが速度場（velocity field）で、これをニューラルネットで学習するのがフローマッチングです。生成時は速度場を時間方向に積分していきます。だから多数のステップが要ります。

フローマップ（flow map） は、この積分をショートカットする発想です。任意の 2 時刻 s と t について「時刻 s の状態を時刻 t の状態へ直接送る写像」X_{s,t} をネットワークにパラメータ化します。形は X_{s,t}(x_s) = x_s + (t−s) v_{s,t}(x_s) で、v_{s,t} は「s から t へ一気に跳ぶときの平均速度（mean velocity）」です。訓練は、多ステップの教師フローから知識を移す蒸留（distillation）か、データから直接学ぶ自己蒸留（self-distillation）で行われます。これにより 1〜2 回の関数評価で生成できるようになります。

問題は、既存のフローマップがすべて 固定キャンバス に縛られていることです。連続空間なら固定次元 d、離散空間なら固定系列長 L。論文は 3 節の冒頭で「標準的な連続フローの主要な限界は、状態空間が初期化時に固定されることにある」と述べています。

i

なぜ単純に次元を増やせないのか。理由は数学的にはっきりしています。s < t で次元が d(s) < d(t) と増えるとき、出発点 x_s は R^{d(s)} に、到着点 x_t は R^{d(t)} に住んでいます。次元の違う空間の間には微分同相写像（滑らかで逆も滑らかな 1 対 1 対応）が存在しません。したがって p_s を p_t へ運ぶ固定次元の速度場も存在しません。フローという枠組みそのものが、次元の変化を許さないのです。

可変長生成を扱う研究は他にもあります。論文は FlexMDMs や Edit Flows をはじめとする複数の手法を挙げていますが、これらは可変長生成を実現する一方で「フローマップのパラダイムの外側にとどまる」と位置づけています。

提案手法：何をしたのか

1. 拡張生成フロー（EFlow）：次元スケジュールを導入する

出発点はシンプルです。固定次元 d を、時刻の関数である 次元スケジュール d(t) に置き換えます。d は非減少、つまり 0 ≤ s < t ≤ 1 のとき常に d(s) ≤ d(t) です。時刻 t の状態は x_t ∈ R^{d(t)} に住みます。この上で、フローを 3 つの部品に分解します。

拡張作用素（expand operator）E_{s,t} は、次元を持ち上げる役です。R^{d(s)} × R^{d(t)−d(s)} → R^{d(t)} という型を持ち、扱いやすい条件付き分布から引いたノイズ ε を使って、足りない座標を埋めます。どこに新しい座標を置くかという配置スキームには 3 通りが示されています。

スキーム 1Concatenation（連結）

末尾に新しい座標を足します。自己回帰的な系列生成や、点群への点の追加に自然な形です。

スキーム 2Positional Insertion（位置挿入）

系列の任意の位置に ε の要素を挿入します。任意長の系列生成や、穴埋め（infilling）に向きます。

スキーム 3Child Expansion（子拡張）

新しい座標それぞれを親の座標 pa(i) に紐づけ、x^ε_s[i] = x_s[pa(i)] + σ ε_i と初期化します。構造を持った状態を粗いところから細かいところへ作っていく生成に適します。

挿入するノイズとその配置は、決定論的に決めてもよいですし、専用のネットワーク Ê に予測させることもできます。

局所時間座標（local time coordinate） は、時計を揃える工夫です。座標ごとに生まれた時刻が違うので、そのままでは「いまどれくらいノイズが取れているか」を共通に語れません。そこで成分 i に、挿入時刻 t^ins_i を基準にした自分だけの時計 t_i = (t − t^ins_i)/(1 − t^ins_i) ∈ [0,1] を割り当てます。挿入された瞬間は t_i = 0 で、時刻 1 で t_i = 1 になります。

輸送（transport） は、拡張された状態を前に進める役です。すでに挿入済みの座標（t^ins_i ≤ t）は標準的な速度場 b_t に従って自分の局所時間に沿って積分され、まだ挿入されていない座標は速度 0、つまり動きません。

この 2 段を合成したものが EFlow の定義です。

Φ_{s,t} := X_{s,t} ∘ E_{s,t}: R^{d(s)} → R^{d(t)}

まず次元を持ち上げ、次に運ぶ、という順番です。これは周辺分布を合わせるだけでなく、x_s と x_t の完全なカップリング（どの出発点がどの到着点に対応するか）まで定めます。理論面では次のことが示されています。

命題 3.1押し出しとしての拡張作用素

拡張作用素は、挿入ノイズの分布を「押し出した（pushforward）」ものとして書けます。押し出しとは、ある分布を写像で送った先にできる分布のことです。つまり「時刻 s の状態 x_s を与えたときの時刻 t の状態の分布は、ノイズ ε の分布を拡張作用素で送ったものになる」ということです。

命題 3.2拡張フローは PDMP

拡張フローは、次元の異なる空間をすべて重ならないように一つに束ねた集合の上の 区分決定論的マルコフ過程（PDMP） です。生成子は「滑らかに運ぶ輸送項」と「座標が挿入される瞬間のジャンプ項」の和になります。座標が生まれる瞬間には不連続なジャンプが起きるため、フローの言葉だけでは全区間 t ∈ [0,1] を通した記述ができません。

系 3.1変数変換公式

変数変換公式（密度の変化を追う式）が導かれます。密度の変化に効くのは挿入済みの座標だけで、まだ生まれていない座標は挿入時刻まで密度に寄与しません。

注意 3.1固定次元フローの回収

従来の固定次元フローは、R^{d(t)} が t によらず一定という特別な場合として回収されます。

2. 拡張フローマップ（EFM）：次元の増加と時間の前進を一度に

EFlow はまだ多ステップの積分を必要とします。ここに少ステップ生成を持ち込むのが EFM です。拡張補間路の上で、2 つの時刻の間を 単一の学習済みステップ で移す写像を作ります。

Φ_{s,t}(x_s) := X_{s,t}(E_{s,t}(x_s)) = E_{s,t}(x_s) + (t − s) v_{s,t}(E_{s,t}(x_s))

つまり「次元を上げてから、平均速度で一気に跳ぶ」形です。s → t の極限で瞬時速度に一致するという接条件（tangent condition）を課し、s = t にあたる場合を回帰することで訓練します。回帰ターゲットは、データからの自己蒸留なら x_1^{(t)} − E_{0,t}(x_0)、教師フローからの蒸留なら教師の速度 b̂_t(x_t) です。

!

命題 4.1（実用上の含意が大きい結果）：固定次元のフローマップが満たすべき 3 つの整合条件は、拡張設定でもそのまま成り立ちます。唯一の違いは、条件の一つに現れるヤコビアン（写像が各点で入力をどう伸縮させるかを表す行列）∇_x Φ_{s,t} が 長方形の行列 になることだけです。入力側の次元 d(s) と出力側の次元 d(t) が違うため、行列の縦横のサイズが揃わないのです。既存のフローマップの学習手法をほぼそのまま移植できる、という意味で実用上大きな含意を持ちます。ただし固定次元の場合と違い、フローマップは拡張作用素 Ê_{s,t} と速度 v̂_{s,t} の両方でパラメータ化されます。

命題 4.2：EFM は決定論的な写像ではなく 確率的なフローマップ です。確率性は条件付きノイズ ε の明示的な注入から生まれ、t = 1 でクリーンな事後分布を復元します。単一の軌道にコミットせず、将来状態の分布全体を捉えられるということです。

3. 離散版：拡張はトークン挿入、輸送はトークン脱ノイズ

離散データ（分子グラフや文章）へは、カテゴリカル分布の空間であるシンプレックス（simplex）を経由して持ち込みます。この設定では、拡張作用素は トークンの挿入 に、輸送は トークンの脱ノイズ に対応します。直感的には、文章が空の状態から少しずつ単語の枠を増やしながら、同時にそれぞれの枠の中身を意味の通る単語へ整えていくイメージです。

  1. 挿入スケジュール α_t を訓練時に固定する

    α_0 = 0、α_1 = 1 とします。位置 i が時刻 t までに挿入済みである確率が α_t です。各位置は「未挿入」か「局所時間 t_i における潜在状態」のどちらかを取ります。

  2. 挿入期待値 I_{s,t}(x_s)[i] を定める

    隣り合う 2 つの活性トークンの間の隙間（ギャップ）i に、区間 (s,t] で挿入されるトークン数の期待値です。I_{s,t}(x_s)[i] = ((α_t − α_s)/(1 − α_s)) I_s(x_s)[i] と書けます。

  3. 挿入損失 L_insert で挿入ヘッドを学習する

    挿入を担当するヘッドに 2 つの教師信号を与えます。s = t にあたる場合は「時刻 t の時点で各ギャップに何本入っているか」を、s < t の場合は「区間 (s,t] で何本入るか」を学習させます。これにより、2 時刻間の挿入本数を直接予測できるようになります（損失の形は Poisson 分布、すなわちまれな事象の個数を表す確率分布の負の対数尤度です）。

  4. 離散の拡張作用素が二項分布に従ってトークンを挿入する

    ギャップごとに決めた本数 ℓ_i だけ潜在トークンを挿入します。この本数を 二項分布（Binomial） ℓ_i ~ Binomial(L − n_s, Î_{s,t}(x_s)[i]/(L − n_s)) から引くのがポイントです。期待値を Î_{s,t} に保ちながら、各ギャップを残りのトークン予算で打ち切ります。

i

なぜ二項分布なのか。この論文で特に読みどころのある議論です。多ステップの場合、1 ステップあたりの挿入は少ないので、残り予算 L − n_s が挿入期待値 Î_{s,t} よりずっと大きくなります。このとき二項分布は Poisson 分布へ収束し、3 節の PDMP が定める微小ジャンプ則と一致します。ところが少ステップで (s,t) が (0,1) に近づくと、1 回でほぼ全長を挿入することになり、事情が変わります。Poisson 分布は上限が非有界で分散が平均に等しいため、この領域では破綻します。一方で二項分布の分散 np(1−p) は p → 1 で消えていくので、正確なカウントへ集中します。多ステップと少ステップの両方を 1 つの定式化で扱うために、二項分布が必要だったわけです。

離散版の EFM 自体は Φ_{s,t}(x_s) := ((1−t)/(1−s)) E_{s,t}(x_s) + ((t−s)/(1−s)) ψ_{s,t}(E_{s,t}(x_s)) という形で、ψ_{s,t} は平均脱ノイザ（mean denoiser）です。各位置の出力がシンプレックス上にあるため、通常のクロスエントロピー損失で最適化できます。命題 5.1 で、連続版と同じ 3 つの整合条件の離散版が示されています。

結果：何が分かったのか

検証は 3 タスクで行われました。連続空間の分子配座生成、離散の分子グラフ生成、そして可変長の言語モデリングです。

分子コンフォーマ生成（連続空間）

分子の 3 次元的な立体配置（コンフォーマ）を生成するタスクです。データセットは GEOM-QM9 と GEOM-Drugs で、テストは各データセット 200 分子（QM9 で 22,409 コンフォーマ、Drugs で 14,324）。評価指標は Coverage（COV、どれだけ網羅できたか）と Average Minimum RMSD（AMR、最も近い相手までの平均距離、単位はÅ）を、recall（R）と precision（P）の両面で見ます。

設定が面白いところです。粗いところから細かいところへの二段階の生成を、原子ごとの局所時間を持つ 単一の挿入フロー で実現しています。

  1. 重原子の骨格をガウスノイズから脱ノイズする

    まず分子の骨格にあたる重原子の配置を作ります。

  2. 途中の時刻で骨格を凍結する

    できあがった骨格をその時点で固定します。

  3. 水素原子を挿入し、骨格の周りだけを解く

    分子グラフから原子数は既に分かっているため、拡張作用素は child expansion の決定論的なケースを使います。速度場のネットワークは公平な比較のため MSGEN が用いる GeoDiff の dual-encoder を流用しています。

  4. （任意）10 ステップの精錬器（refiner）で仕上げる

    追加 10 回の評価だけで、凍結した重原子骨格の周りの局所的な幾何を整え、精度系の指標を一貫して改善します。

比較対象の GeoDiff、SubgDiff、MSGEN といった拡散ベースラインは 500〜1000 回の脱ノイズステップを要します。これに対する結果です。

  • EFlow は拡散ベースラインより 16〜50 倍少ないステップ で、両データセットにおいて競合ないし上回る結果を出しました。
  • GEOM-QM9 での EFlow（20 ステップ）は COV-R 88.51%、COV-P 53.07%。
  • 10 ステップの精錬器を加えた EFlow+R（合計 30 ステップ）は、QM9 で 全手法中最良の AMR-P 0.4876Å を達成しました。
  • 改善が最も顕著なのは最大 181 原子の GEOM-Drugs で、4 指標すべてで最良か次点を占めました。
  • 注目すべきは、まだ蒸留していない EFlow の時点で 多ステップ拡散の性能をごくわずかな予算で上回っていることです。
  • 蒸留後の EFM は 4 ステップ、2 ステップ、さらには 1 ステップ でコンフォーマを生成できます。EFM+R は GEOM-Drugs の 4 指標すべてで単独最良でした（14 ステップで COV-R 87.97/95.45、AMR-R 0.9029/0.8836、COV-P 64.67/73.25、AMR-P 1.1575/1.0875、値は Mean/Median）。

正直な数字も載っています。EFM 単独の 1 ステップ（QM9）は COV-R 69.21/69.23、AMR-R 0.4884/0.4635、COV-P 32.18/29.09、AMR-P 0.6093/0.5794 で、多ステップのベースラインには劣ります。2 ステップ、4 ステップと増やすと段階的に改善し、QM9 の COV-R は 72.83 から 83.62 へ伸びます。

化学的な妥当性も、量子化学計算ソフト Psi4 で確認されています。GEOM-QM9 の 30 分子について 50 コンフォーマずつ生成し、生成したコンフォーマ集団の物性を評価しました。指標は E、E_min、∆ε_avg、∆ε_max、∆ε_min の 5 つで、いずれも参照値との絶対誤差の中央値（単位 eV、低いほど良い）です。各記号が指す物性の詳しい定義は原論文の付録に譲ります。結果は次のとおりです。EFlow+R（30 ステップ）は 5 指標のうち 4 つで、既存手法である RDKit と ConfGF の両方を上回りました。

手法 E↓ E_min↓ ∆ε_avg↓ ∆ε_max↓ ∆ε_min↓
EFlow+R（30 ステップ） 0.4506 0.0731 0.2204 0.1156 0.8717
RDKit 0.8914 0.6629 0.2947 0.1617 0.5196
ConfGF 0.5328 0.1145 0.3207 0.1337 —

単位は eV、参照値との絶対誤差の中央値（低いほど良い）。網掛けは EFlow+R が RDKit・ConfGF の両方を上回った 4 指標。「—」は本記事で数値を挙げていない箇所。

一方で悪化した項目もあります。∆ε_min は 0.8717 で、RDKit の 0.5196 より悪くなっています。また EFM+R（14 ステップ）は E が 2.0521、∆ε_min が 2.6383 など、複数の項目で悪化しました。少ステップ化には代償があるということです。

離散分子グラフ生成

QM9 データセットで、分子をグラフ（ノードが原子、エッジが結合）として直接生成するタスクです。10,000 分子を生成し、Validity（RDKit で有効な分子として解釈できる割合）、Uniqueness（そのうち互いに異なる割合）、FCD（Fréchet ChemNet Distance、参照分布との距離、低いほど良い）で評価します。

コンフォーマ生成と違い、ここではグラフのサイズが事前に分かりません。そのため拡張作用素は、サンプリング時に挿入するノード数を予測する 学習ヘッド になります。脱ノイザは公平な比較のため DeFoG の graph transformer を使っています。多ステップ領域での DeFoG との比較です（Valid↑ / Unique↑ / FCD↓）。

ステップ数 DeFoG EFlow
100 99.2 / 96.2 / 0.134 98.9 / 95.9 / 0.116
50 98.8 / 96.2 / 0.260 98.8 / 96.1 / 0.131
10 88.6 / 92.8 / 1.630 97.9 / 96.1 / 0.390
4 53.6 / 63.1 / 3.008 91.7 / 92.8 / 1.780

100 ステップの予算でも EFlow は FCD で既に DeFoG を上回っており、ステップ予算が縮むほど差が広がります。100 から 10 ステップへ減らしても EFlow の FCD の劣化はわずかで、validity と uniqueness は 95% 超を保ちます。一方 DeFoG は同じ範囲で大きく崩れ、4 ステップでは validity が 53.6% まで落ちました。しかもこれは 蒸留していない EFlow 教師 での結果であり、少ステップ領域にはまだ伸び代があると論文は示唆しています。

蒸留後の少ステップ比較（CFM との対決）です。

ステップ数 CFM EFM
2 91.1 / 97.6 / 0.49 90.0 / 97.9 / 0.40
1 90.0 / 91.8 / 2.14 90.2 / 97.7 / 0.44

2 ステップでは validity と uniqueness が同等で FCD がより低く、1 ステップになると差が広がります。CFM の FCD は 2.14 へ劣化し uniqueness も 91.8 へ落ちるのに対し、EFM は FCD 0.44、uniqueness 97.7% を維持しました。論文はこれを「1 ステップで EFM の FCD は CFM のほぼ 5 分の 1」と表現しています。

可変長の言語モデリング

One Billion Word（LM1B）での無条件テキスト生成です。生成した文を GPT-2 Large で評価した生成 perplexity（低いほど良い）と、生成トークン分布のエントロピーを報告しています。語彙サイズは 30,522（bert-base-uncased トークナイザ）と大きいため、挿入時刻を区間 [0, 0.5] に制限し、脱ノイズに十分な時間を確保しています。

文に対して離散拡張補間路を定義し、各トークンに独立な挿入時刻を割り当て、学習ヘッドがギャップごとの挿入数を予測します。単一のネットワークがトークンのカテゴリを脱ノイズしながら、系列が空から完全長へ成長していきます。アーキテクチャは DDiT backbone（12 ブロック、hidden 768、12 attention head）で、挿入ヘッドが追加するパラメータはわずか 0.79M です。訓練は 4×NVIDIA B200 GPU、global batch 512、2×10^5 ステップで行われました。

まず多ステップ領域で、固定長のフロー言語モデル FLM との比較です（生成 PPL↓ / エントロピー）。

意義と限界

この論文の位置づけは、個別のタスクで最高性能を出したというより、生成モデリングの見方を組み替えたところにあります。生成を「次元が増えていく周辺分布の間を、拡張補間路に沿って輸送すること」として捉え直しました。部品は 2 つだけです。条件付きノイズで状態をより高次元の空間へ持ち上げる拡張作用素と、持ち上がった状態をターゲット分布へ押し進める輸送写像です。

理論的な収まりの良さも特筆できます。既存の固定キャンバスのフローとフローマップは、拡張作用素が恒等写像である特別な場合としてこの枠組みに回収されます。整合条件も、ヤコビアンが長方形になる点を除けば既存のものと一致します。そのうえで、分子配座生成・分子グラフ生成・言語モデリングという性質の異なる 3 タスクに、領域とサンプリング予算を問わない「単一の統一レシピ」として適用できることが示されました。

限界も明示されています。

限界 1検証規模

GEOM-QM9 は最大 29 原子、GEOM-Drugs は最大 181 原子、LM1B は最大 128 長の系列にとどまります。

限界 2スケーリングの未検証

二項分布による挿入のパラメータ化と、可変サイズ入力に対する輸送写像の安定性は理論的に示されています。しかし実際にスケールさせるのは容易ではありません。次元ごとに局所時間座標へ条件づける仕組みが複雑さを持ち込むうえ、1 つのクリーンデータに対して取り得る補間路の組み合わせが非常に多いためです。著者らは、より大きな次元へスケールさせるにはさらなるチューニングが必要であり、計算コストが大きいため経験的に十分探索できなかったと述べています。

限界 31 ステップ生成の課題

言語生成の 1 ステップサンプリングでモード崩壊が起きています。

限界 4少ステップ化の代償

分子コンフォーマ生成では、蒸留後の EFM+R が化学的物性の複数項目で EFlow+R より悪化しました。

今後の方向としては、条件付きノイズ分布をガウスに限定せず挿入次元をサンプルする平均・共分散を学習可能にすること、挿入時刻に条件づけた別の補間路を設計すること、挿入時刻の順序に構造を課すことが挙げられています。また、本論文は次元が増加する補間路に限定していますが、PDMP による構成では 次元が減少する操作 も考えうると述べられています。

コードとモデルは GitHub（github.com/sophtang/ExpandingFlowMaps）と Hugging Face（huggingface.co/ChatterjeeLab/ExpandingFlowMaps）で公開されています。

まとめ

生成モデルが縛られてきた「最初に決めたキャンバスのサイズを変えられない」という制約を、この論文は正面から外しにいきました。鍵は、次元スケジュールに沿って状態を持ち上げる拡張作用素と、持ち上がった状態を運ぶ輸送写像への分解、そして座標ごとに時計を分ける局所時間座標です。次元が跳ぶ瞬間があるためフローの言葉では記述しきれない過程を、区分決定論的マルコフ過程として捉え直したところに理論的な工夫があります。分子配座生成では拡散ベースラインの 16〜50 分の 1 のステップで競合ないし上回り、分子グラフ生成と可変長テキスト生成でも少ステップ領域で優位を示しました。1 ステップ生成のモード崩壊やスケーリングの検証といった課題は残るものの、出力のサイズそのものを学習と制御の対象にする道筋を示した仕事です。

用語集

フローマッチング（flow matching）
ノイズからデータへ向かう連続的な経路上の速度場を学習し、それを積分して生成する枠組み。
確率的補間路（stochastic interpolant）
ノイズ分布とデータ分布の間を連続時間でつなぐ経路を構成する枠組み。線形補間 I_t(x_0, x_1) = (1−t) x_0 + t x_1 が代表例。
フローマップ（flow map）
任意の 2 時刻 s, t について ODE の状態を直接出力する決定論的写像 X_{s,t}。多ステップの積分を少ステップに蒸留するために使う。
平均速度（mean velocity）v_{s,t}
x_s から (t−s) 幅のステップを取るときの速度。t = s の極限で瞬時速度に帰着する。
拡張補間路（expanding interpolant）
固定次元 d を、時刻とともに非減少な次元スケジュール d(t) に置き換えた補間路。
拡張作用素（expand operator）E_{s,t}
現在の状態に条件づけて、新しい座標やトークンで状態空間を広げる学習可能な作用素。配置スキームとして concatenation、positional insertion、child expansion が示されている。
輸送写像（transport map）X_{s,t}
拡張された状態を補間路に沿って前進させる学習可能な写像。
ヤコビアン（Jacobian）
写像が各点で入力をどう伸縮させるかを表す行列。拡張設定では入力と出力の次元が違うため、縦横のサイズが揃わない長方形の行列になる。
押し出し（pushforward）
ある分布を写像で送った先にできる分布。拡張作用素は、挿入ノイズの分布の押し出しとして次の時刻の分布を定める。
局所時間座標（local time coordinate）t_i
挿入時刻の異なる各成分を共通の [0,1] の時計上で脱ノイズするための時間の射影。t_i = (t − t^ins_i)/(1 − t^ins_i)。
PDMP（piecewise-deterministic Markov process、区分決定論的マルコフ過程）
滑らかな決定論的輸送と、ランダムに起きるジャンプからなる確率過程。拡張フローはこの枠組みで特徴づけられる。
平均脱ノイザ（mean denoiser）ψ_{s,t}
離散状態空間における平均速度の等価なパラメータ化。出力がシンプレックス上にあるためクロスエントロピーで訓練できる。
シンプレックス空間 ∆^{V−1}
語彙サイズ V のカテゴリカル分布の空間。離散データを連続的な分布として表すことで、連続向けのフローマップ手法を離散設定へ転用できる。
挿入期待値（insertion expectation）
区間 (s,t] の間に、ある隙間へ挿入されるトークン数の期待値。
挿入ハザード（insertion hazard）λ_t
λ_t := α̇_t/(1−α_t)。時刻 t における未挿入トークンの瞬時挿入率。
COV / AMR
コンフォーマ生成の標準指標。Coverage は閾値内で一致した割合、Average Minimum RMSD は最近傍までの平均最小 RMSD。recall は参照側、precision は生成側を基準にした版。
FCD（Fréchet ChemNet Distance）
ChemNet の埋め込み空間で測った、生成分子と参照分子の分布間距離。低いほど良い。
Validity / Uniqueness
生成グラフのうち有効な分子として解釈できる割合と、そのうち互いに異なるものの割合。
生成 perplexity（generative perplexity）
生成テキストを GPT-2 Large で評価した perplexity。低いほど良い。
モード崩壊（mode collapse）
生成モデルが出力の多様性を失い、限られたパターンばかり出すようになる現象。EFM の 1 ステップサンプリングで観測された。
